# Ispezione Turbine Eoliche con YOLOv11
**Tesi di Laurea in Ingegneria - Angelo Melfi**

Questo repository contiene il materiale relativo alla tesi di laurea sull'automazione dell'ispezione delle turbine eoliche tramite computer vision.

## 📂 Contenuto del Repository
* **Documentazione**: Tesi in formato PDF e file sorgente LaTeX.
* **Scripts Python**: Codice per il preprocessing del dataset, l'addestramento del modello e l'inferenza (test).
* **Configurazione**: File `.yaml` per la gestione delle classi e dei percorsi.
* **Risultati**: Grafici di performance, matrici di confusione e pesi del modello (`.pt`).
